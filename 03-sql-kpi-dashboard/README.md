# SQL + интерактивный KPI-дашборд

SQL-слой поверх SQLite и готовый интерактивный HTML-дашборд (Plotly) по выручке
мультирыночного e-commerce: динамика по месяцам, YoY по рынкам, разбивка по категориям,
эффект промо-акций.

> **О данных.** Тот же синтетический датасет, что и в `02-ecommerce-rfm-cohort` (детали
> генерации — в его README). Здесь он взят под другим углом: не сегментация клиентов, а
> регулярная KPI-отчётность по рынкам, категориям и промо.

## Бизнес-вопрос

Как выглядит регулярная KPI-отчётность для коммерческой команды: сколько выручки, по каким
рынкам и категориям, какой средний чек — и работают ли промо-акции так, как от них ожидают.

## Как посмотреть

Открой `dashboard.html` в любом браузере (файл самодостаточный, работает офлайн — весь
Plotly.js встроен внутрь).

## Результаты

- **Total Revenue**: €189 881.11 за 2024–2025, **3 071 заказ**, **AOV €61.83**
- **YoY**: 2024 → 2025 рост с €84 524 до €105 357, **+24.6%**
- **По категориям**: Fragrance — крупнейшая категория (35.7% выручки), дальше Skincare (19.6%),
  Makeup (15.9%), Haircare (15.0%), Wellness (13.8%)
- **По рынкам**: Россия — крупнейший рынок и с наибольшим приростом (€28.9K → €41.8K,
  +44.6%), Мексика на втором месте (€19.2K → €24.6K, +28.3%); Казахстан — практически
  без роста (+0.02%)
- **Промо-эффект**: средний чек в промо-периодах (€58.37) оказался **ниже**, чем в обычные
  дни (€62.14), при среднем дисконте 6.9% против 1.3%. В этом датасете промо не увеличивает
  число заказов сверх сезонного тренда, только снижает цену — по простому before/after
  сравнению эффект выглядит неоднозначно.

## Почему промо-вывод — не просто красивая цифра

Это намеренно неочевидный результат: он показывает, что простое сравнение "выручка в
промо vs не в промо" не доказывает эффективность акции — нужен **incrementality-тест**
с holdout-группой, чтобы отделить прирост от каннибализации обычного спроса. Ровно тот
навык критического мышления, который проверяют на собеседованиях на Pricing/Promo Analyst
и Growth Analyst.

## Файлы

- `dashboard.html` — готовый интерактивный дашборд (открывать в браузере)
- `build_dashboard.py` — код: SQL-запросы → агрегаты → дашборд
- `sql/kpi_queries.sql` — те же SQL-запросы отдельным файлом для читаемости
- `data/` — customers.csv, orders.csv
- `exports/` — агрегированные CSV (monthly_kpi, promo_effect, category_breakdown, yoy_by_country)

## Как воспроизвести

```
pip install pandas plotly
python3 build_dashboard.py
```
