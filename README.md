# Product / Data Analytics — Portfolio

Три небольших законченных проекта: A/B-тестирование, сегментация клиентской базы,
KPI-отчётность. Стек — Python (pandas, scipy, matplotlib, plotly), SQL (SQLite).

## Проекты

- **[`01-ab-test-retention`](01-ab-test-retention)** — A/B-тест на реальном публичном
  датасете мобильной игры Cookie Cats: хи-квадрат тест, bootstrap-доверительные интервалы.
- **[`02-ecommerce-rfm-cohort`](02-ecommerce-rfm-cohort)** — RFM-сегментация и когортный
  анализ удержания клиентов, SQL (SQLite) + Python.
- **[`03-sql-kpi-dashboard`](03-sql-kpi-dashboard)** — SQL-слой и интерактивный HTML-дашборд
  (Plotly): выручка, AOV, YoY, эффект промо-акций.

Данные и источники по каждому проекту — в его собственном README.
