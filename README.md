# Product / Data Analytics — Portfolio

Три небольших законченных проекта: A/B-тестирование, сегментация клиентской базы,
KPI-отчётность. Python (pandas, scipy, matplotlib, plotly), SQL (SQLite).

- **[`01-ab-test-retention`](01-ab-test-retention)** — A/B-тест на реальном датасете
  мобильной игры Cookie Cats: хи-квадрат тест, bootstrap-доверительные интервалы.
- **[`02-ecommerce-rfm-cohort`](02-ecommerce-rfm-cohort)** — RFM-сегментация и когортный
  retention, SQL + Python.
- **[`03-sql-kpi-dashboard`](03-sql-kpi-dashboard)** — SQL-слой и интерактивный дашборд:
  выручка, AOV, YoY, эффект промо.

Данные и источники — в README каждого проекта.
